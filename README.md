## Installation

1. Use 22.x.x version (22.14.0 or upper) of Node.js
2. Clone repo:

   ```bash
   git clone git@github.com:ArturKhelshtein/battleship.git
   cd battleship
   ```

3. Set dependencies:

   ```bash
   npm install
   ```

## Usage

**Development**

`npm run start:dev`

* App served @ `http://localhost:8181` with nodemon

**Production**

`npm run start`

* App served @ `http://localhost:8181` without nodemon
